09. Glossary

Key Terminology & Definitions

Simple definitions of core AI and video processing concepts.

ResNet-50
50-layer deep Convolutional Neural Network used to convert raw video keyframe pixels into 2048-dimensional feature vectors.
Transformer Encoder
3-layer PyTorch neural network utilizing self-attention mechanisms to model global temporal narrative context across frames.
0/1 Knapsack DP
Dynamic Programming algorithm that selects the maximum importance video shots without exceeding the target summary duration.
OpenAI Whisper
State-of-the-art Automatic Speech Recognition (ASR) model that transcribes video audio into timestamped speech text.
Bhattacharyya Distance
Statistical measure of color distribution overlap used to detect visual scene changes between consecutive video frames.
Multimodal AI
AI architecture that unifies visual video frames, audio speech, and natural language text into a single coherent output.
